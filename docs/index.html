🏥 Clinical Context Assistant

Chrome Extension for Healthcare Professionals

📋 Overview

The Clinical Context Assistant is a Chrome extension designed to help healthcare professionals access clinical information and context while browsing medical content online. This tool provides quick access to clinical guidelines, drug interactions, and medical references.

🚀 Quick Start

1. Clone the repository: git clone https://github.com/wiseaihub/Clinician.git 2. Load in Chrome: - Go to chrome://extensions/ - Enable Developer mode - Click "Load unpacked" - Select the project folder

✨ Key Features

  • Clinical Context: Instant access to medical guidelines
  • User-Friendly: Clean, intuitive interface
  • Fast Performance: Lightweight and responsive
  • Secure: Manifest v3 compliance

📁 Project Structure

Clinical_Context_Assistant/ ├── manifest.json # Extension configuration ├── popup.html # Main interface ├── popup.js # Core functionality ├── styles.css # Styling ├── images/ # Icons and assets └── README.md # Documentation

🛠️ Development

This extension is built with vanilla HTML, CSS, and JavaScript. No build process is required - simply load the extension in Chrome and start developing.

⚠️ Medical Disclaimer: This extension is designed to assist healthcare professionals but should not replace professional medical judgment, diagnosis, or treatment. Always consult with qualified healthcare providers for medical decisions.
